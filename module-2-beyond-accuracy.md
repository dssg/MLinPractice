# Module 2 · Beyond the Basic Model and Accuracy
{: .no_toc }

**Weeks 9–14.** Additional topics beyond building an accuracy-focused model: the
modern ML systems you'll build (foundation models and agents) and how to evaluate
them, as well as considerations around ethics, causality, field evaluation,
robustness, uncertainty, interpretability, and fairness — applied to the project.

them up to date. Links below go straight to each session.
